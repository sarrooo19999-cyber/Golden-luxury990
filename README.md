# Golden Luxury — النسخة المصححة

## تشغيل الموقع
افتح `index.html`، أو شغّل خادمًا محليًا من هذا المجلد باستخدام `npx serve .`.

## مهم عند النشر
ارفع **محتويات هذا المجلد نفسها** إلى الاستضافة، بحيث يكون `index.html` في جذر الموقع مباشرة، ويكون مجلد `assets` بجانبه.
لا ترفع المجلد الأب الذي يحتوي هذا المجلد؛ حتى لا يظهر الموقع داخل مسار فرعي أو تتعطل مسارات التنسيق.

## بنية الملفات
- `index.html`
- `assets/css/styles.css`
- `assets/js/config.js`
- `assets/js/products.js`
- `assets/js/app.js`
- `assets/img/`

## ملاحظات
- تم التأكد من وجود ملفات التنسيق والبرمجة والصور التي يستدعيها ملف HTML.
- تم فحص ملفات JavaScript نحويًا، ولا توجد أخطاء صياغة.
- أسعار الذهب المباشرة تعتمد على الإنترنت ومصدر API خارجي؛ عند تعذر الاتصال يستخدم الموقع الأسعار الاحتياطية في `assets/js/config.js`.
- بيانات المتجر ورقم واتساب تعدّل من `assets/js/config.js`.
